# Customer Data Cleaning Using Python

## Project Overview
This project demonstrates how to clean customer data using Python and Pandas. It identifies duplicate records, handles missing values, and generates a data-cleaning report.

## Tools Used
- Python
- Pandas
- Google Colab

## Tasks Performed
- Inspected the original dataset.
- Identified missing values and duplicate rows.
- Removed duplicate records.
- Filled missing ages using the median.
- Replaced missing cities with "Unknown".
- Exported the cleaned dataset and cleaning report.

## Results
- Original records: 5
- Cleaned records: 4
- Duplicate rows removed: 1
- Missing values before cleaning: 2
- Missing values after cleaning: 0

## Project Files
- `Customer_Data_Cleaning.ipynb` — Python notebook.
- `cleaned_customers.csv` — cleaned customer dataset.
- `data_cleaning_report.csv` — cleaning summary.

## How to Run
Open the notebook in Google Colab and run the cells in order.

## Note
This is a learning project using sample customer data. Missing-value handling rules should be chosen according to the requirements of the actual dataset.
